# 🎨 RoomStyle AI

**Interior style classifier and paint colour recommender.** Upload a photo of a room; the app predicts its interior design style and suggests matching paint colours.

Built for *Foundations of Machine Learning* (NMIMS MPSTME). The project compares a neural network on raw features against **PCA + MLP** and **LDA + MLP**, with cross-validation and a logistic regression baseline.

## How it works

1. **Data:** room photos from Unsplash, one folder per style (`raw_images/<style>/`).
2. **Features (`features.py`):** v2 gives 91 features: RGB histogram (48), HSV histogram (32), 3×3 edge-energy grid (9), brightness mean/std (2). The legacy v1 (48 RGB-histogram features) is still supported; the app picks the right one from the saved model.
3. **Models (`train_model.py`):** logistic regression, MLP, PCA(95% variance) + MLP, LDA + MLP, all as scikit-learn `Pipeline`s so scaling/PCA/LDA are fitted on training data only (no leakage).
4. **Evaluation:** stratified 80/20 split plus 5-fold CV on the training set; best model chosen by CV accuracy.
5. **App (`app.py`):** Streamlit UI showing prediction, confidence, paint suggestions and the per-style probabilities.

## Project structure

```
roomstyle-ai/
├── app.py                  # Streamlit app
├── features.py             # Shared feature extraction (v1 + v2)
├── extract_features.py     # Raw images -> X_features.npy / y_labels.npy
├── train_model.py          # Trains, compares PCA / LDA / MLP, saves best pipeline
├── images.py               # Image count per style folder
├── style_classifier.pkl    # Trained pipeline (scaler [+PCA/LDA] + classifier)
├── label_encoder.pkl       # Fitted LabelEncoder
├── X_features.npy, y_labels.npy
├── reports/                # Plots generated by train_model.py
├── requirements.txt        # Runtime deps (used by Render)
├── requirements-train.txt  # + matplotlib, for training
├── render.yaml             # Render deployment config
├── .streamlit/config.toml
└── README.md
```

## Run locally

```bash
pip install -r requirements-train.txt
python -m streamlit run app.py
```

### Retrain (optional)

```bash
python images.py raw_images             # check counts
python extract_features.py raw_images   # builds 91-feature matrix
python train_model.py                   # trains, plots to reports/, saves pipeline
```

## Deploy on Render

1. Push this folder to a GitHub repo (include the `.pkl` files).
2. On [render.com](https://render.com): **New → Blueprint**, pick the repo (it reads `render.yaml`).
   Or **New → Web Service** with:
   - Build command: `pip install -r requirements.txt`
   - Start command: `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`
   - Env var: `PYTHON_VERSION = 3.12.7`
3. Deploy. The free plan sleeps after inactivity, so the first load can take about a minute.

`scikit-learn` is pinned to the version used to train the pickles (1.8.0). If you retrain with another version, update the pin in `requirements.txt`.

## Results (current shipped model, 48 colour-histogram features)

| Model | CV accuracy | Test accuracy |
|---|---|---|
| Logistic Regression | 0.439 | 0.453 |
| MLP (raw) | 0.443 | 0.516 |
| PCA (95%) + MLP | 0.408 | 0.562 |
| LDA + MLP | 0.439 | 0.562 |

4 classes, 319 images, 64 test images. Chance is 25%. Differences between models are within noise at this sample size. Re-run `extract_features.py` + `train_model.py` to get results with the richer v2 features.

## Limitations

- Colour/edge statistics say little about shape, layout or objects, so similar palettes across styles get confused.
- Small dataset, so results vary between splits.
- Paint names are hand-mapped suggestions, not official brand shades.
- A "coastal" class was dropped for lack of images.
